리니지2M 중국 유저 동향 툴 — 사용 안내

■ 설치할 것 없습니다

1. 이 폴더를 압축 해제된 상태 그대로 둡니다.
   (바탕화면이나 D드라이브 등 아무 곳이나 괜찮습니다)

2. '실행.bat' 파일을 더블클릭합니다.

3. 검은 명령창이 뜨고, 잠시 후 브라우저가 자동으로 열립니다.
   → 이 검은 창은 닫지 마세요. 닫으면 툴이 꺼집니다.

4. 브라우저가 자동으로 안 열리면 주소창에 직접 입력하세요.
   http://localhost:8501

※ 검은 창에 아래 영문 화면이 나오는 경우

     Welcome to Streamlit!
     ... please enter your email address below ...
     Email:

   아무것도 입력하지 말고 Enter 키만 한 번 누르세요.
   그러면 바로 진행됩니다. 최초 1회만 나옵니다.


■ 사용법

1. 조사 소스를 고릅니다. (기본값 그대로 두셔도 됩니다)
2. 조회 시작일 / 종료일을 정합니다.
3. '수집·분석 실행' 버튼을 누릅니다.
4. 수 분 걸립니다. 중간에 창을 닫지 마세요.

실행 중에 Chrome 또는 Edge가 보이지 않게 잠깐 동작합니다. 정상입니다.


■ 종료

검은 명령창에서 Ctrl + C 를 누르거나, 창을 닫으면 됩니다.


■ 결과를 볼 때 알아둘 것

이 툴은 중국 공개 커뮤니티(QQ 공식 채널, TapTap, Bilibili)에서
로그인 없이 볼 수 있는 게시글만 수집합니다.

- 댓글, 이미지 안의 텍스트, 비공개 글은 수집되지 않습니다.
- 인기 노출 화면을 함께 활용하므로 반응이 큰 글에 편중될 수 있습니다.
- 따라서 '전수 조사'가 아니라 '공개 웹 표본'입니다.

카테고리별 건수는 상대적 참고치로만 보시고,
"유저의 몇 %가 이렇게 생각한다" 같은 해석은 하지 마세요.
판단이 필요하면 '원문·번역' 탭에서 실제 글을 확인하시면 됩니다.


■ 안 될 때

"python 폴더가 없습니다"
 → 압축을 다시 풀어 주세요. 폴더 구조가 깨졌습니다.

"Chrome/Edge 자동 수집 실행 실패"
 → PC에 Chrome이나 Edge가 필요합니다. Edge를 한 번 실행해 보세요.

번역 실패 글이 몇 건 나옴
 → 정상입니다. 실패해도 중국어 원문은 그대로 남습니다.

그 외 오류
 → 검은 명령창의 내용을 캡처해서 알려주세요.
